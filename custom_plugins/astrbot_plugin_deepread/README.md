# 深读 · astrbot_plugin_deepread

> 让小蜗读懂群里分享的网站卡片——**只要不是视频，都能读进去并整理总结**。

**定位：给小蜗挂一个工具，不是给你加一堆指令。** 你主动问她，她才去解析；
她不会自动插话、不会主动总结任何东西。

## 它解决什么问题

群里分享的东西五花八门：小黑盒卡片、潮玩星球卡片、公众号文章、GitHub 链接、群文件、一长串合并转发。
以前小蜗看到的只是一串冷冰冰的 URL，不知道里面讲什么。

现在你问她一句「看看刚才那个卡片」，她就能讲出里面是啥。

## 它怎么做到的

**核心洞察：分享卡片里本来就带着信息。**

QQ 分享卡片（`Json` 消息段）的 `meta` 字段里，**腾讯客户端已经替我们抓好了**标题、摘要、来源、缩略图、跳转链接。
这是随消息一起来的，零网络请求、零风控、零成本——这正是本插件的主力信息源。

为什么不去抓网页？实测结论（详见 `DESIGN.md`）：

| 站点 | httpx | curl_cffi（chrome 指纹） | Playwright（真实 Chrome） |
|---|---|---|---|
| 公众号 | ❌ | ❌ | ❌ |
| 知乎 / B站网页 / 掘金 / 百度百科 | ❌ | ❌ | ❌ |
| GitHub / CSDN / V2EX / 少数派 / 博客 | ✅ | — | ✅ |

服务器是机房 IP，被各大平台风控直接拒绝——**换客户端没用**。所以设计成：

```
L0 卡片元数据（主力·永远可用）
 └─ 有链接时可选补抓 L1 网页正文 / L2 官方 API（B站 view、GitHub REST）
     └─ 群文件 / 合并转发 / 图片（L3）
```

拿到了就补全，拿不到就如实说「只拿到标题和摘要」，**不编造**。

## 用法

**不用打指令，直接问小蜗就行。**

```
看看这个卡片
刚才那个链接讲的啥
群里分享的那篇文章说什么
```

小蜗会自己判断并调用 `deepread_share`。三种问法都能落地：

| 你怎么问 | 内容从哪来 |
|---|---|
| **引用**那条分享消息再问 | 从被引用的消息里取 |
| 说「刚才那个」「潮玩的卡片」 | 从**静默缓存**里按关键词找 |
| 直接把链接发给她 | 当场抓取 |

### 为什么需要「静默缓存」

这是必须说明的一点：工具被调用时，小蜗拿到的是**你当前那句话**（「看看刚才那个卡片」），
这句话里是没有卡片的。所以插件会在群消息流里**静默记下**最近的分享——
**只记录，不回复、不解析、不打扰任何人**。

注意区分两件事：

- 被动**记录** → 只有这样才能听懂「刚才那个」。必须有。
- 被动**回复** → 自动总结并插话。**本插件不做**，小蜗只在你问的时候才动。

缓存按会话隔离（群/私聊分开），默认记最近 5 条、30 分钟过期，纯内存不落盘。

## 视频卡片会自动跳过

命中以下任一条件即判定为视频，交给 `astrbot_plugin_parser` 等专门插件，本插件不重复响应：

- 域名命中 `bilibili.com` / `b23.tv` / `douyin.com` / `kuaishou.com` / `youtube.com` / `tiktok.com` 等
- 卡片 `view` 字段为 `video`
- 卡片 `meta` 里含 `video` 子键

黑名单可在配置里改（`video_hosts`）。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `cache_size` | `5` | 静默记住最近多少条分享（只记录，不回复）|
| `cache_ttl` | `1800` | 缓存有效期（秒），过期就忘 |
| `skip_video_cards` | `true` | 跳过视频卡片 |
| `video_hosts` | B站/抖音/快手/YT… | 视频站黑名单 |
| `enable_l1_direct` | `true` | 直连抓网页正文 |
| `enable_l2_api` | `true` | 用 B站/GitHub 官方 API |
| `enable_l3_local` | `true` | 解析群文件和合并转发 |
| `max_chars` | `12000` | 送模型的正文上限 |
| `fetch_timeout` | `15` | 抓取超时（秒）|
| `max_items` | `5` | 单次处理条目上限 |
| `summary_model` | 空 | 指定总结模型，留空用会话模型 |
| `persona_style` | `true` | 是否带小蜗口吻 |
| `reject_private_ip` | `true` | 拒绝内网地址（防 SSRF）|

## 维护提示

**站点规则集中在一处。** `core/fetchers.py` 的 `SITE_RULES` 是唯一的站点适配点，
某站改版只需改这一个文件，不用翻遍代码。

**卡片解析不硬编码类型。** `core/cards.py` 遍历 `meta` 下所有子键并递归摊平，
平台换结构也能挖出字段——这是刻意为之，别改成固定键列表。

## 零新增依赖

只用 AstrBot 环境自带的 `httpx` / `beautifulsoup4` / `lxml` / `markdownify`。
`bs4` 缺失时自动降级到内置 `html.parser`。

**刻意不引入 playwright / selenium / 任何浏览器内核**——服务器总内存仅 1685MB，
实测浏览器峰值多占 300MB 且对风控站点无效。
